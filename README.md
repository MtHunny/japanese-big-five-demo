# Big Five 性格チェック

IPIP日本語50項目版を使った、非公式のBig Five自己評定Webアプリです。自己理解の手がかりとして今回の回答を5因子の得点にまとめます。性格の断定や医学的・心理学的な診断は行いません。IPIPや日本語訳提供者の公式アプリではありません。

HTML・CSS・Vanilla JavaScriptのみで動作する静的サイトです。フレームワーク、外部CDN、外部フォント、追加の依存ライブラリ、ログイン、バックエンド、データベース、アクセス解析は使用しません。スマートフォンとPCで利用できます。

## ローカルで実行する

ビルド・パッケージのインストールは不要です。リポジトリのルートで、Python 3の標準HTTPサーバーを起動します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザで [http://127.0.0.1:8000](http://127.0.0.1:8000) を開きます。停止はターミナルで `Ctrl+C` を押します。JavaScriptのES Modulesを使用するため、HTMLの直接オープン（`file://`）ではなくHTTP経由で確認してください。

モバイル表示はブラウザの開発者ツールのデバイス表示で確認できます。

GitHub Pagesでは、リポジトリのルートの `index.html` と `styles.css`、`js/` をそのまま配信できます。リソースは相対パスのためプロジェクト配下のURLでも動作します。公開設定の変更やデプロイ用ワークフローの追加は行っていません。

## 回答の流れ

1. 開始画面で「回答をはじめる」を選びます。途中回答がある場合は「続きから回答」「最初から回答」を表示します。最初から回答すると、以前の途中回答は削除します。
2. 50問を掲載順に1問ずつ表示します。以下の5段階から選ぶと、選択表示の後、自動で次の問いに進みます。選択中は入力をロックして連続タップによる二重遷移を防ぎます。
   - 1：まったく当てはまらない
   - 2：あまり当てはまらない
   - 3：どちらともいえない
   - 4：やや当てはまる
   - 5：とてもよく当てはまる
3. 「戻る」で以前の回答を確認・修正できます。「いったん中断」で開始画面に戻れます。再読み込み・再訪時も開始画面から再開できます。
4. 50問すべてに回答すると、5因子の合計得点と横棒グラフ、説明を表示します。

## 採点方法

正方向は回答値、逆方向は `6 - 回答値` とし、因子ごとに10項目を合計します。各因子の範囲は10〜50点です。

| 画面上の因子名 | 原尺度の正式名称（公式採点キー） | 正方向の項目番号 | 逆方向の項目番号 |
| --- | --- | --- | --- |
| 外向性 | Surgency or Extraversion | 1, 11, 21, 31, 41 | 6, 16, 26, 36, 46 |
| 協調性 | Agreeableness | 7, 17, 27, 37, 42, 47 | 2, 12, 22, 32 |
| 誠実性 | Conscientiousness | 3, 13, 23, 33, 43, 48 | 8, 18, 28, 38 |
| 情緒安定性（神経症傾向の反転） | Emotional Stability | 9, 19 | 4, 14, 24, 29, 34, 39, 44, 49 |
| 開放性 | Intellect or Imagination（知性・想像力） | 5, 15, 25, 35, 40, 45, 50 | 10, 20, 30 |

誠実性は、計画性・整理整頓・責任を持って物事に取り組む傾向を扱います。情緒安定性（神経症傾向の反転）は、神経症傾向と反対向きの得点です。第5因子は画面上で「開放性」と表示します。この尺度では『知性・想像力（Intellect or Imagination）』として測定されています。知能検査の得点ではありません。これらは表示名称・説明の変更であり、原尺度の項目や採点方法は変更していません。

結果に人口平均との差、偏差値、パーセンタイル、高・中・低の判定は表示しません。グラフは全因子共通の10〜50点の尺度で、10点を始点、50点を終点とします。

起動時に、全50項目がちょうど1因子に属し、各因子が10項目であることを検証します。未回答や1〜5の整数以外を含む回答からは採点を確定しません。

## テスト

Node.js 22以降の標準テストランナーで実行できます。追加依存のインストールは不要です。

```sh
node --test tests/*.test.mjs
```

自動テストの対象：

- 全3：全因子30点
- 全5：外向性30、協調性34、誠実性34、情緒安定性（神経症傾向の反転）18、開放性38点
- 全1：外向性30、協調性26、誠実性26、情緒安定性（神経症傾向の反転）42、開放性22点
- 正方向5・逆方向1：全因子50点、逆の組み合わせ：全因子10点
- 各項目の得点方向、採点キーの重複・欠損、未回答・不正値の拒否
- 保存直後の再訪、途中再開、戻って修正、中断、最初から開始
- 遷移中の二重回答・戻る操作等の拒否、完了時の保存削除、再読み込みで結果を復元しないこと
- 破損した保存データの破棄、保存機能が利用できない場合の継続と通知

ブラウザでも、数問回答→戻って修正→再読み込み→続きから回答→50問完了→再読み込み、の順に確認できます。開発者ツールのlocalStorageで、途中にだけ下記キーが存在し、完了時に消えることを確認できます。

## プライバシー

- 回答値・表示位置は、回答途中のみこのブラウザのlocalStorageの `big-five-demo:in-progress:v1` に保存します。同じサイト・同じブラウザでのみ再開できます。他の端末やブラウザには同期しません。
- 最後の回答時に途中データを削除します。結果はページのメモリ上にのみ保持し、再読み込みで消えます。回答履歴は保存しません。
- 未完了のデータは再開のために残ります。「最初から回答」またはブラウザのサイトデータ削除で消せます。共用端末では保存データにご注意ください。
- localStorageが制限されている場合や容量不足の場合は画面に通知します。その場合もメモリ上で回答できますが、再開できない場合があります。削除に失敗した場合も通知するため、ブラウザ設定からこのサイトのデータを削除してください。
- アプリは回答データを外部に送信しません。通信APIは使用せず、CSPの `connect-src 'none'` でも接続を制限します。URLにも回答や結果を含めません。
- サイトの配信時は通常のページ・ファイル取得が発生し、配信サービス側の通信ログはそのサービスに依存します。出典リンクを選ぶとIPIPサイトへ移動します。リンク先に回答値は渡しません。
